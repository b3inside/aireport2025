# 2025 AI Report

按月份回看 2025 年的 AI 大事、新模型和产品发布。<br>
A month-by-month look at the AI launches and milestones that shaped 2025.

## 本地运行 · Run locally

需要 Node.js 和 npm，已用 Node.js 22 验证。<br>
Requires Node.js and npm. Tested with Node.js 22.

```sh
git clone https://github.com/b3inside/aireport2025.git
cd aireport2025
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:8080`。<br>
Open the local URL printed in your terminal. The default is `http://localhost:8080`.
